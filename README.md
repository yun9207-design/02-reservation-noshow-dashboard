# 02 · Reservation No-Show Dashboard

예약·노쇼·취소 빈자리 회복 비즈니스를 **화면으로 조작하며 이해하는 학습형 웹앱**입니다.

이 저장소는 30개 바이브코딩 비즈니스 실습 시리즈의 **02번**입니다. 단순 UI 목업이 아니라 가상 데이터를 이용해 다음 흐름이 실제로 연결됩니다.

> 예약 요청 → 예약금 모의 결제 → 예약 확정 → 방문/완료 → 취소 또는 노쇼 → 빈자리 매칭 → 대기자 모의 제안 → 수락 → 회복 예약 → 통계/이력

## 현재 구현

- 예약 중복·영업시간·담당자 제공 서비스 검사
- 예약 요청 / 예약금 모의 결제 / 확정 / 도착 / 완료 / 취소 / 노쇼
- 취소 시 정책에 따른 예약금 모의 환불·차감
- 취소 빈자리와 대기 고객의 서비스·시간·담당자 조건 매칭
- 제안 홀드 시간, 수락·거절·만료, 수락 직전 일정 재검사
- CSV 고객/예약 가져오기와 반영 전 검사
- 고객 방문·노쇼 이력
- 실습 시각 이동
- localStorage 저장, 동시 탭 변경 감지, JSON 백업·복원
- 리포트·감사 이력·CSV 내보내기
- 단일 `preview.html` 오프라인 실행본

## 실제로 하지 않는 것

- 실제 문자/카카오톡/이메일 발송
- 실제 예약 플랫폼 동기화
- 실제 결제·환불
- 실제 로그인·사용자 권한
- 실제 고객 개인정보의 안전한 서버 저장

화면에서 이 기능들은 **모의 기능**으로 명확히 표시합니다.

## 학습 순서

1. `학습 가이드`의 1번 시나리오를 실행합니다.
2. `일정 · 빈자리`에서 예약 요청을 만들고 예약금·확정 흐름을 봅니다.
3. `대기자 · 회복`에서 취소 슬롯 `RSV-1005`를 대기자에게 제안합니다.
4. 제안을 수락하고 `리포트 · 이력`에서 회복 매출이 바뀌는지 확인합니다.
5. `설정 · 백업`에서 실습 시각을 바꾸고 노쇼 규칙을 시험합니다.

## 개발 규칙

AI 코딩 도구는 `AGENTS.md`와 `CLAUDE.md`를 먼저 읽어야 합니다. 기능을 단순화하거나 모의 기능을 실제 연동처럼 표현하지 마세요.
