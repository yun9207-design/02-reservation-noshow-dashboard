# Backend roadmap

현재는 백엔드 없는 학습 버전입니다. 실제 서비스화 후보가 되었을 때 다음 순서로 확장합니다.

1. **인증**: 실제 사용자 로그인과 세션
2. **권한**: 지점/직원별 예약 접근 제어
3. **DB**: 고객·서비스·직원·예약·대기자·감사로그 분리
4. **동시성**: 같은 빈자리를 두 사람이 동시에 예약하지 못하도록 트랜잭션/락
5. **결제**: 예약금 승인·취소·환불을 서버 API와 웹훅으로 처리
6. **메시지**: 제안/리마인더 실제 발송과 수신 동의 관리
7. **예약 플랫폼 연동**: 공식 API가 있을 때 조회/변경 어댑터 구현
8. **운영 로그**: 실패 재시도, 관리자 승인, 감사 이력
9. **개인정보**: 최소 수집, 삭제/보존, 암호화, 접근 로그

첫 상용화에서 모든 항목을 동시에 만들지 말고, 실제 고객에게 필요한 연결부터 단계적으로 붙입니다.
