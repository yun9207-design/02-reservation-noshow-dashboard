# Feature matrix

| 영역 | 현재 | 실제 서비스 전환 시 |
|---|---|---|
| 예약 등록·겹침 검사 | 실제 로컬 동작 | 서버 트랜잭션/동시성 제어 |
| 예약금 | 모의 상태 변경 | 결제사 서버 API·웹훅 |
| 취소·노쇼 정책 | 실제 규칙 계산 | 실제 약관/결제 정책 검증 |
| 대기자 매칭 | 실제 로컬 계산 | 서버 스케줄러·다중 지점 고려 |
| 빈자리 제안 | 모의 기록 | 문자/카카오/이메일 API |
| 제안 수락 | 실제 로컬 새 예약 생성 | 서버에서 원자적 재검사·예약 |
| 로그인 | 없음 | 인증 + 역할/지점별 권한 |
| 저장 | localStorage | DB + 백업 + 접근제어 |
| CSV | 실제 브라우저 파싱 | API/관리자 업로드 + 서버 검증 |
| 리포트 | 로컬 상태에서 계산 | DB 집계/분석 파이프라인 |
| AI | 없음 | 필요성 확인 후 별도 서버 호출 |
