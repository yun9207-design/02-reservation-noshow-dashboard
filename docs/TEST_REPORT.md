### P0-1 · 정책 값 검증 (`529dcf1`)

검증 근거는 커밋 기록입니다(이 문서를 쓴 세션이 P0-1 작업을 직접 수행하지는 않았습니다). 회귀 테스트 25개가 추가됐고 총 66개였습니다.

- `slotMinutes <= 0`(음수, NaN 포함)이 저장되어 `candidateSlots`가 무한루프하던 문제를 막습니다.
- 여섯 숫자(슬롯, 영업 시작·종료, 취소 기준 시간, 노쇼 유예, 제안 홀드)는 `src/domain/policy.ts`의 한 정의를 정책 화면, `updatePolicy`, 백업 복원, 저장소 읽기가 함께 씁니다.
- 잘못된 값이 저장소나 백업에서 들어오면 기본값으로 바꾸고 나머지 자료는 유지하며 감사 이력에 남깁니다.

P0-2 작업 중 다시 확인한 P0-1 동작(브라우저): 정책 값이 복구된 백업을 복원한 뒤에도 일정 화면이 약 0.7초 안에 정상 렌더링됐고, 정책 화면에서 잘못된 슬롯 값(300)을 입력하면 오류가 표시되고 저장 버튼이 잠겼으며 저장소는 바뀌지 않았습니다.
